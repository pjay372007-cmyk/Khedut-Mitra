# Production Master Dataset - Final Class Mapping Standards

## Consolidated Priority Class Mapping
Mappings and standard crop classifications:
- Chilli: Bacterial_Spot, Healthy, Nutrient_Deficiency, Spot, White_Spot
- Cotton: Bacterial_Blight, Curl_Virus, Healthy
- Groundnut: Healthy, Late_Spot, Nutrient_Deficiency
- Papaya: Anthracnose, Bacterial_Spot, Curl_Virus, Healthy, Ring_Spot
- Potato: Early_Blight, Healthy, Late_Blight
- Sugarcane: Banded_Chlorosis, Brown_Rust, Brown_Spot, Dried, Grassy_Shoot, Healthy, Mosaic_Virus, Pokkah_Boeng, Red_Rot, Red_Spot, Ring_Spot, Sett_Rot, Smut, Viral_Disease, Wilt, Yellow
- Tomato: Bacterial_Spot, Blight, Early_Blight, Healthy, Late_Blight, Leaf_Mold, Mosaic_Virus, Septoria_Leaf_Spot, Spider_Mites, Target_Spot, Yellow_Leaf_Curl
- Wheat: Brown_Rust, Healthy, Yellow_Rust

Exclusions:
- Mapped and excluded cashew, cassava, grape, citrus, apple, blueberry, cherry, orange, peach, raspberry, squash, strawberry categories from non-priority crops.
