## 8. Deployment Recommendations

### Primary Model: EfficientNet-B0
- **Recommended for:** Server-side inference, backend API, cloud deployment
- **Export format:** ONNX (for ONNX Runtime) or TorchScript (for LibTorch)
- **Inference speed:** ~15–30ms per image on GPU, ~200ms on CPU
- **Input:** `224×224 RGB image`, normalized with ImageNet stats
- **Output:** Softmax probability over 49 classes

### Mobile Model: MobileNetV3
- **Recommended for:** Mobile app (Android/iOS), embedded devices, edge inference
- **Export format:** ONNX → convert to TFLite or CoreML for mobile
- **Model size:** ~10 MB (vs ~25 MB for EfficientNet-B0)
- **Inference speed:** ~8–15ms on mobile NPU

### Integration Notes
```python
# Load and run EfficientNet-B0 with ONNX Runtime
import onnxruntime as ort
import numpy as np

session = ort.InferenceSession('models/onnx/efficientnet_b0_best.onnx')
input_name = session.get_inputs()[0].name
# img_array: np.float32 array of shape (1, 3, 224, 224), ImageNet-normalized
logits = session.run(None, {input_name: img_array})[0]
predicted_class_idx = np.argmax(logits)
```
