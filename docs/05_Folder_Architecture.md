## 2. File Organization Rules

-   **Frontend Assets:** No stylesheet declarations or long JS libraries should clutter `index.html`. CSS must live under `/css/` and JS under `/js/`.
-   **Static Data Databases:** Any JSON file loaded or generated by python builders must reside inside `/data/` to keep clean datasets separated from functional Python scripts.
-   **Knowledge Extraction:** Python files responsible for downloading, crawling, scraping, or parsing PDF text must go to `/knowledge_engine/` to avoid root level clutter.
-   **Model Binaries:** Executable neural net layers and serialized binaries must reside inside `/models/` subdirectories.
